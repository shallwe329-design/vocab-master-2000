# VOCAB MASTER 2000

사용자가 직접 입력한 영어 단어와 숙어로 자신만의 Day를 만드는 학습 웹앱입니다.

## 구현된 기능
- 영단어 / 숙어를 각각 별도로 입력
- 하루 학습량을 원하는 정수로 직접 설정
- 입력한 총 개수와 하루 학습량으로 Day 자동 계산 (마지막 Day는 남은 개수만 표시)
- 뜻, 품사, 유의어, 예문, 예문 해석 입력
- 미국식 영어 발음 듣기, 느린 발음, 예문 듣기 (브라우저 음성 기능)
- 학습 기록, 정답률, 누적 오답 확인
- 객관식 / 직접 입력 테스트
- 브라우저 자동 저장
- Supabase 이메일 회원가입/로그인 및 클라우드 저장용 SQL 포함

## 실행 방법
1. Node.js LTS를 설치합니다.
2. 압축을 푼 폴더에서 터미널을 열고 `npm install` 실행
3. `npm run dev` 실행
4. 브라우저에서 http://localhost:3000 접속

## Supabase 연결
1. Supabase 프로젝트의 Project URL과 publishable key(또는 anon public key)를 확인합니다.
2. 프로젝트 루트의 `.env.example`을 복사해 `.env.local`로 이름을 바꿉니다.
3. `.env.local` 안에 두 값을 입력합니다.
4. Supabase > SQL Editor에서 `supabase/schema.sql` 전체를 실행합니다.
5. 개발 서버를 껐다가 `npm run dev`로 다시 실행합니다.
6. 사이트의 계정 설정에서 회원가입/로그인 후 클라우드 저장을 누릅니다.

주의:
- `service_role` 또는 secret key를 브라우저 환경변수에 넣지 마세요.
- 현재 클라우드 저장은 로그인 후 저장 버튼을 누르는 방식입니다. 브라우저 자동 저장은 기본으로 동작합니다.
- 이 버전은 클라우드에서 데이터를 자동으로 불러오는 기능은 아직 포함하지 않습니다. 다른 기기 간 자동 동기화는 후속 구현이 필요합니다.
- 학습 테스트는 현재 선택한 Day의 단어/숙어 뜻을 직접 입력하거나 객관식으로 확인합니다.
